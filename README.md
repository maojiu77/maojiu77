## 正在做

### [随打英语 · TypeEnglish](https://github.com/maojiu77/type-english)

在 Mac 上打中文时，旁边就能看到英文。使用苹果本地翻译生成预览，也可以用 Codex 润色成自然的英式英语。

| 体验 | 实现 |
| --- | --- |
| 保持原来的打字节奏 | 非激活浮窗，不替换原文、不自动发送消息 |
| 本地预览，可选 AI | Apple Translation + Codex CLI |
| 兼容不同输入场景 | 辅助功能输入框读取 + 手动框选 OCR |

**目前阶段：实验性原型。** 正在改善微信输入区的框选保留与窗口跟随体验，跨应用兼容性仍在验证。

[查看项目与使用说明 →](https://github.com/maojiu77/type-english)
